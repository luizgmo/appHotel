# Hotel Estancia Barra Bonita Management App

Este projeto é um aplicativo de gerenciamento de hotel desenvolvido com React Native e Expo. O aplicativo é projetado para otimizar as operações do hotel, permitindo a gestão de reservas, pedidos, inventário, escalas de trabalho e outras funções essenciais.

> ⚠️ **Nota:** Esta é a versão mais básica do projeto, focada na estrutura inicial e nas principais funcionalidades do aplicativo. A aplicação foi disponibilizada utilizando **dados mockados** para fins de demonstração, testes ou validação de interface, sem necessidade de integração completa com o backend.

## Páginas Principais

- **`curriculo.js`**: Página para gerenciamento de informações curriculares dos funcionários.
- **`detalhesPedido.js`**: Detalhamento dos pedidos de compra e status de processamento.
- **`escala.js`**: Visualização e gerenciamento das escalas de trabalho dos funcionários.
- **`inventario.js`**: Página para controle e monitoramento do inventário do hotel.
- **`menuCompra.js`**: Interface para seleção de itens e criação de novos pedidos de compra.
- **`pedidos.js`**: Página principal para visualização de todos os pedidos realizados.
- **`perfil.js`**: Configuração e atualização do perfil de usuário.
- **`recebimentoPedido.js`**: Gerenciamento do recebimento de mercadorias e atualização de status.
- **`requisicao.js`**: Gerenciamento de requisições internas feitas pelos departamentos do hotel.
- **`telaPrincipal.js`**: Tela inicial do aplicativo, com um resumo das operações e acesso rápido às principais funções.
